## 🚀 איך להתחיל?

### 1. שכפלו את הריפו
```bash
git clone https://github.com/DorElias/python-advanced-course.git
cd python-advanced-course
```

### 2. התקינו את הספריות הנדרשות
```bash
pip install -r requirements.txt
```

הספריות שיותקנו:
- pandas - ניתוח נתונים
- openpyxl - עבודה עם אקסל
- requests - תקשורת HTTP
- aiohttp - בקשות אסינכרוניות (Asyncio)
- matplotlib - גרפים
- notebook ו-ipykernel - מחברות לימוד

### 3. הפעילו את מחברות הלימוד
```bash
jupyter notebook
```

### 4. התחילו ללמוד!
פתחו את התיקייה `content/day01` והתחילו את הקורס.

**יום 4 (תקשורת אינטרנט):** המחברות הרגילות (`1_Requests_Basics`, `2_Working_with_APIs`, `Summary`) מניחות שיש אינטרנט.
אם אין אינטרנט או שהשירות לא עובד, השתמשו בגרסאות האופליין באותה תיקייה: `1_Requests_Basics_Offline`, `2_Working_with_APIs_Offline`, `Summary_Offline`.
בגרסאות האלה, אם הבקשה נכשלת, הקוד טוען תשובה שמורה מקובץ - זו עקיפה לכיתה בלבד, ולא משהו שעושים בקוד אמיתי.

### אופציונלי: שימוש ב-PyCharm
אם אתם רוצים להשתמש בסביבת פיתוח מקצועית יותר במקום Jupyter Notebook,  
ראו את [מדריך ההתקנה של PyCharm](PYCHARM_SETUP.md).

**שימו לב:** אתם לא חייבים להתקין PyCharm - Jupyter Notebook מצויין ללימוד!
